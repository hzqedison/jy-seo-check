# Topic Cluster + E-E-A-T 框架（内容 / 工具 / 电商型站点）

> 下例以工具类产品为主，其他行业（SaaS、电商、媒体）按意图类比替换占位 `X`。

## Topic Cluster：用"支柱页 + 子集群"替代零散文章

按**用户意图**分支柱：
- **商业意图 / tool-solution**：`X tool`、`best X`、`X vs Y`
- **根因 / root problem**：`how to fix X`、`why is X happening`
- **症状 / user complaint**：`X not working`、`X error/lag/drop`

每个支柱 = 1 个支柱页（Pillar）+ N 个子页（Cluster）；支柱 ↔ 子页**双向内链**；子页指向转化页 / 工具页。让搜索引擎理解站点话题权威，整体抬排名。

## 子集群维度（建词库时横切，组合扩展）

- 实体维度：具体产品 / 品类 / 场景
- 平台维度：pc / mobile / web / console…
- **区域维度**：country / region（`X in usa/europe/asia`，配 hreflang，对接区域化）
- 表现 / 原因 / 设置维度
- **对比 / 替代维度**：`A vs B`、`X alternative`、`X review`（高商业意图，高转化）

## E-E-A-T 落地（获胜页范式）

- **Experience**：第一手实测、可复现对比（开/关产品的前后数据）。
- **Expertise**：真正回答用户问题；可视化分级表/图表。
- **Authoritativeness**：专题沉淀 + 高质量外链 + **具名作者 + 资历**（近年 Google 看重）。
- **Trustworthiness**：排版清晰、信息准确、定期更新（标 last updated）。

> 获胜页常见范式 = **可视化数据（分级表/对比表）+ 可操作步骤 + 真实测试**，在信息型查询里往往胜出。

## 工具页（差异化护城河）

产品若有特色能力，做成**在线工具页**（如检测/计算/测速类），承接工具类核心词 + 内嵌转化 CTA（用完即转化）。用 `SoftwareApplication` / `WebApplication` Schema。工具页承接工具类核心词、用完即转化，是被广泛验证的有效打法。

## 内容纪律

- **质量优先**：AI 辅助 + 人审 + 提供独立价值（搜索引擎不歧视 AI，质量才是关键）。
- **主题聚焦**：避免"什么有量写什么"导致主题涣散；资讯/热点页占比收敛。
- **常态化剪枝**：低价值页 保留 / 重写合并 / noindex 或删（别只在"热点退去后"做）。
- **长效优先**：做长青常青资产，不依赖事件热点（热点流量来去快、不沉淀）。

## 把内部数据 SEO 化

产品的内部数据（如用户实际效果改善、节点对比）是被低估的资产，可做成 case study / 数据报告 / 可视化对比页，天然满足 Experience 与 Trustworthiness。
